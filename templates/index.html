💡 Apa Sebenarnya Ilmu INFORMATIKA Itu?

Informatika adalah disiplin ilmu mengenai studi, perancangan, dan pembuatan sistem komputasi, serta prinsip-prinsip yang menjadi dasar perancangan tersebut. Informatika mempelajari bagaimana data mentah dikumpulkan, diproses melalui algoritma logika, disimpan dengan aman, dan disajikan menjadi informasi yang bermanfaat bagi manusia.

Di SMK Kelas X (Fase E), Informatika menjadi mata pelajaran fondasi kejuruan terpenting untuk membangun digital mindset, kemampuan problem solving tingkat tinggi, dan bekal menyongsong era Revolusi Industri 4.0 serta Artificial Intelligence (AI).

⚙️ Siklus Kerja Komputasi (IPOS):
1. INPUT ⌨️
Memasukkan data via keyboard, mouse, sensor, kamera, atau file CSV/Excel.
2. PROCESS 🧠
CPU/GPU mengolah data dengan instruksi logika matematika & algoritma.
3. OUTPUT 🖥️
Menampilkan hasil ke layar, printer, speaker, atau dashboard visualisasi.
4. STORAGE 💾
Menyimpan data permanen di SSD, harddisk, cloud server, atau database SQLite.

💡 Mengapa Python Menjadi Bahasa Pemrograman Nomor 1 di Dunia? SMK Kelas XI & XII

Python diciptakan oleh Guido van Rossum dan dirilis pertama kali pada tahun 1991 dengan filosofi desain yang menekankan keterbacaan kode (*readability*). Sintaks Python sangat ringkas dan bersih menyerupai bahasa Inggris sehari-hari, menjadikannya bahasa ideal bagi siswa pemula SMK hingga insinyur profesional Google, NASA, dan Netflix.

Di industri teknologi modern, Python adalah bahasa standar emas untuk Kecerdasan Buatan (AI), Data Science, Web Development (Backend), otomatisasi sistem jaringan, serta scripting praktis.

⚡ 4 Keunggulan Utama Python:
  • Sintaks Sederhana: Tanpa titik koma (;) wajib di akhir baris.
  • Indentasi Bersih: Struktur blok kode diatur oleh spasi rapi.
  • Ekosistem Kaya: Ribuan pustaka gratis siap pakai.
  • Multiplatform: Berjalan di Windows, Linux, Mac, & Cloud.
🖨️ Bab 1: Cetak Teks & Komentar
Dasar Output
Fungsi print() digunakan untuk menampilkan teks atau nilai variabel ke konsol layar. Tanda pagar (#) digunakan untuk komentar yang tidak akan dieksekusi.
# 1. Menampilkan teks string print("Halo, SMK Cahaya Pertiwi!") # 2. Cetak beberapa nilai sekaligus print("Nilai Ujian:", 90, "Predikat:", "A") # 3. F-String (Formatted String modern) nama = "Alexa" skor = 88.5 print(f"Siswa {nama} memperoleh skor {skor}")
💡 Tips Siswa: Selalu gunakan f-string (huruf f sebelum tanda petik) saat menggabungkan teks dengan angka variabel agar tidak terjadi TypeError.
📦 Bab 2: Variabel & Aturan Penamaan
Wadah Memori
Variabel adalah nama wadah penyimpan nilai data di memori komputer. Nilai variabel dapat diubah sewaktu-waktu (*re-assignment*).
# Deklarasi variabel nama_siswa = "Rian Saputra" # snake_case umur = 16 uang_saku = 20000 # Mengubah nilai variabel uang_saku = uang_saku - 5000 # Sekarang 15000 print(uang_saku)
💡 Aturan Wajib Variabel:
• Harus diawali huruf atau underscore (_), TIDAK boleh diawali angka (misal 1nilai salah).
• Tidak boleh pakai spasi (gunakan nama_lengkap).
• Peka huruf besar-kecil: kelas beda dengan Kelas!
🏷️ Bab 3: Tipe Data & Casting
4 Tipe Primitif
Python secara otomatis mendeteksi tipe data variabel (*Dynamic Typing*). Fungsi type() untuk mengecek, dan fungsi casting untuk mengubah tipe.
teks = "100" # str (String) bulat = 25 # int (Integer) desimal = 3.75 # float (Desimal) aktif = True # bool (Boolean) # Konversi tipe (Type Casting) angka = int(teks) # Jadi int 100 total = angka + bulat # 125 (Bisa dihitung!)
💡 Jebakan Pemula: "10" + "20" menghasilkan teks "1020". Lakukan int("10") + int("20") untuk mendapatkan angka 30!
➗ Bab 4: Operator Matematika & Logika
Kalkulasi & Logika
Simbol-simbol untuk operasi aritmatika, perbandingan nilai, dan operasi logika gabungan.
# Aritmatika: + - * / // % ** print(7 / 2) # 3.5 (Bagi pecahan) print(7 // 2) # 3 (Bagi bulat) print(7 % 2) # 1 (Sisa bagi/modulus) print(2 ** 3) # 8 (Pangkat: 2^3) # Logika: and, or, not nilai = 80 kehadiran = 95 lulus = (nilai >= 75) and (kehadiran >= 80)
💡 Operator Perbandingan: == (sama dengan), != (tidak sama), >= (lebih besar atau sama). Ingat: = adalah assignment, == adalah pembanding!
🔀 Bab 5: Percabangan (If, Elif, Else)
Pengambilan Keputusan
Mengarahkan alur eksekusi program berdasarkan kondisi benar (*True*) atau salah (*False*). Indentasi (spasi menjorok) wajib 4 spasi.
skor = 82 if skor >= 90: grade = "A (Sangat Memuaskan) 🏆" elif skor >= 75: grade = "B (Kompeten) ✅" elif skor >= 60: grade = "C (Cukup) ⚠️" else: grade = "D (Remedial Wajib) 📝" print(f"Hasil Ujian: {grade}")
💡 Aturan Emas: Jangan lupakan tanda titik dua (:) di akhir baris if, elif, dan else, serta baris bawahnya wajib di-tab/spasi menjorok!
🔁 Bab 6: Perulangan (For & While Loop)
Otomatisasi Loop
Menjalankan sekumpulan perintah berulang kali tanpa harus mengetik kode yang sama berulang kali.
# 1. For loop dengan range(start, stop) # Catatan: range(1, 6) mencetak 1 sampai 5! for i in range(1, 6): print(f"Putaran ke-{i}") # 2. While loop dengan counter hitungan hitung = 3 while hitung > 0: print(f"Hitung mundur: {hitung}") hitung -= 1 # kurangi 1 agar tidak infinite!
💡 Keyword Penting: Gunakan break untuk menghentikan loop seketika, dan continue untuk melompati iterasi saat ini ke putaran berikutnya.
📋 Bab 7: List & Dictionary
Koleksi Data
List [] menyimpan data urut berbasis indeks (mulai dari 0), sedangkan Dictionary {} menyimpan pasangan kunci-nilai (*key-value*).
# List: Daftar Nama Siswa siswa = ["Budi", "Siti", "Rian"] siswa.append("Dewi") # Tambah elemen print(siswa[0]) # Indeks 0: 'Budi' # Dictionary: Data Siswa Lengkap profil = { "nama": "Alexa Angel", "nisn": "0108492001", "nilai_kejuruan": 88.5 } print(profil["nama"]) # Output: Alexa Angel
💡 Fungsi Penting: len(siswa) menghitung jumlah elemen, del siswa[0] menghapus elemen, dan profil.keys() melihat seluruh kunci.
⚙️ Bab 8: Fungsi (def) & Return
Modularitas Kode
Fungsi adalah blok kode terorganisir yang dapat dipanggil berkali-kali menggunakan kata kunci def dan mengembalikan hasil dengan return.
# Mendefinisikan fungsi perhitungan def hitung_kkm(nilai_tugas, nilai_uts): rata_rata = (nilai_tugas + nilai_uts) / 2 if rata_rata >= 75.0: return f"LULUS ({rata_rata})" return f"REMEDIAL ({rata_rata})" # Memanggil fungsi hasil = hitung_kkm(80, 85) print(hasil) # LULUS (82.5)
💡 Fungsi Bawaan Top Python: len() (panjang), sum() (total), max() (terbesar), min() (terkecil), round() (pembulatan), dan sorted() (pengurutan).
🛡️ Bab 9: Penanganan Kesalahan (Error Handling: Try - Except)
Di dunia industri perangkat lunak, program tidak boleh tiba-tiba mati (*crash*) saat pengguna salah memasukkan data. Gunakan blok try ... except untuk menangkap kesalahan secara aman: 
# Contoh Pencegahan Crash (ZeroDivisionError & ValueError)
def bagi_angka(pembilang, penyebut):
    try:
        hasil = float(pembilang) / float(penyebut)
        return f"Hasil: {hasil}"
    except ZeroDivisionError:
        return "⚠️ Error: Angka penyebut tidak boleh nol (0)!"
    except ValueError:
        return "⚠️ Error: Input harus berupa angka valid!"

print(bagi_angka(10, 2))   # Hasil: 5.0
print(bagi_angka(10, 0))   # Menghasilkan pesan peringatan aman, program tidak crash!

💡 Mengapa Sistem Informasi Sekolah & Industri Wajib Memakai Database (RDBMS)? SMK Kelas XI & XII

Database (Basis Data) adalah kumpulan data terstruktur yang disimpan secara elektronik dalam sistem komputer. Berbeda dengan lembar kerja spreadsheet (seperti Excel) yang mudah rusak saat diakses banyak orang bersamaan, RDBMS (Relational Database Management System) seperti MySQL, PostgreSQL, dan SQLite dirancang untuk mengelola jutaan baris data secara aman, konsisten, dan sangat cepat.

Di industri teknologi dan rekayasa perangkat lunak, database adalah jantung penyimpan data untuk aplikasi web, e-commerce, perbankan, sistem absensi sekolah, serta platform Artificial Intelligence (AI).

⚡ 5 Konsep Kunci Database RDBMS:
  • Tabel (Table): Tempat penyimpanan data dua dimensi (baris & kolom).
  • Kolom (Field/Column): Atribut data tertentu (misal: nisn, nama).
  • Baris (Record/Row): Satu kesatuan data utuh milik seorang siswa.
  • Primary Key (PK): Kunci unik pembeda antar baris (tak boleh duplikat/NULL).
  • Foreign Key (FK): Kunci tamu penghubung relasi ke tabel lain.
🔑 Bab 1: Anatomi Tabel & Kunci Relasi
Fondasi RDBMS
Tabel RDBMS terdiri dari kolom (field) dan baris (record). Primary Key (PK) adalah identitas unik tiap baris, sedangkan Foreign Key (FK) menghubungkan tabel anak ke tabel induk tanpa redundansi.
-- Tabel 1: Tabel Induk (Parent) CREATE TABLE kelas ( id INT PRIMARY KEY, nama_kelas VARCHAR(50) ); -- Tabel 2: Tabel Anak (Child) berelasi FK CREATE TABLE siswa ( id INT PRIMARY KEY, nama VARCHAR(100), kelas_id INT, FOREIGN KEY (kelas_id) REFERENCES kelas(id) );
💡 Tips Siswa: Primary Key dianalogikan seperti NISN atau Nomor KTP yang dijamin unik untuk setiap orang dan tidak pernah bernilai kosong (NOT NULL).
📚 Bab 2: Kategori Perintah SQL
Standar SQL
SQL terbagi menjadi 3 rumpun utama yang selalu menjadi soal inti ujian kejuruan SMK: DDL (mengatur wadah/struktur tabel), DML (mengolah isi data CRUD), dan DCL (hak akses & keamanan).
-- 1. DDL: Mengubah struktur skema lemari CREATE, ALTER, DROP, TRUNCATE -- 2. DML: Mengolah data dokumen (CRUD) SELECT (Read), INSERT (Create), UPDATE (Update), DELETE (Delete) -- 3. DCL & TCL: Hak akses & transaksi GRANT, REVOKE, COMMIT, ROLLBACK
💡 Jembatan Keledai: DDL mengatur bentuk rak/wadah database, sedangkan DML memanipulasi barang/data yang ditaruh di dalam rak tersebut.
🏗️ Bab 3: DDL - CREATE TABLE
Struktur Tabel
Perintah CREATE TABLE mendefinisikan skema tabel: nama kolom, tipe data (INT, VARCHAR, DECIMAL, DATE), serta aturan kendala (constraints).
CREATE TABLE siswa_smk ( id INT AUTO_INCREMENT PRIMARY KEY, nisn VARCHAR(10) UNIQUE NOT NULL, nama VARCHAR(100) NOT NULL, jurusan VARCHAR(30) DEFAULT 'RPL', nilai DECIMAL(5,2) DEFAULT 0.0, tgl_daftar DATE );
💡 Tips Siswa: AUTO_INCREMENT otomatis membuat nomor urut 1, 2, 3... sehingga guru/admin tidak perlu menghitung ID secara manual.
📥 Bab 4: DML - INSERT INTO
Input Data (Create)
Perintah INSERT INTO digunakan untuk memasukkan rekaman data baru ke dalam tabel, baik satu baris tunggal maupun banyak baris sekaligus (multi-row insert).
-- 1. Tambah 1 data siswa INSERT INTO siswa (nisn, nama, kelas, nilai) VALUES ('1001', 'Ahmad Fauzi', 'XI RPL 1', 88.5); -- 2. Multi-insert banyak baris sekaligus INSERT INTO siswa (nisn, nama, kelas, nilai) VALUES ('1002', 'Budi Santoso', 'XI RPL 1', 92.0), ('1003', 'Citra Dewi', 'XII RPL 2', 79.5);
💡 Tips Siswa: Tipe data teks (VARCHAR) dan tanggal (DATE) wajib diapit tanda petik satu ('teks'), sedangkan angka tidak perlu tanda petik.
🔍 Bab 5: DML - SELECT & Kolom
Query Data (Read)
Perintah SELECT membaca data dari tabel. Anda bisa menampilkan seluruh kolom dengan tanda *, memilih kolom tertentu, atau memberi nama alias dengan AS.
-- 1. Mengambil semua kolom tabel SELECT * FROM siswa; -- 2. Memilih kolom spesifik + Alias (AS) SELECT nama AS nama_lengkap, nilai AS skor_cbt FROM siswa; -- 3. Mengambil daftar kelas unik (tanpa duplikat) SELECT DISTINCT kelas FROM siswa;
💡 Tips Siswa: Memilih nama kolom spesifik (bukan SELECT *) mempercepat kinerja aplikasi secara drastis saat tabel memiliki ribuan baris.
🎯 Bab 6: Filter Kriteria (WHERE)
Logika Filter
Klausa WHERE menyaring baris berdasarkan syarat: operator matematika (=, !=, >=), logika (AND, OR), serta pencarian kata dengan LIKE.
-- 1. Filter nilai di atas KKM SELECT * FROM siswa WHERE nilai >= 75.0; -- 2. Logika ganda AND (keduanya harus benar) SELECT * FROM siswa WHERE kelas = 'XI RPL 1' AND nilai >= 85.0; -- 3. Pencarian teks diawali huruf 'A' SELECT * FROM siswa WHERE nama LIKE 'A%';
💡 Tips Siswa: Tanda persen (%) pada LIKE mewakili sembarang karakter berapa pun panjangnya (contoh: %putra%).
📊 Bab 7: ORDER BY & LIMIT
Ranking & Urutan
ORDER BY mengurutkan baris secara menaik (ASC) atau menurun (DESC). LIMIT membatasi jumlah data yang tampil (sangat ideal untuk fitur Ranking Siswa).
-- 1. Top 5 Siswa dengan Nilai Tertinggi SELECT nama, kelas, nilai FROM siswa ORDER BY nilai DESC LIMIT 5; -- 2. Urutkan nama siswa dari A sampai Z SELECT nama, kelas FROM siswa ORDER BY nama ASC;
💡 Tips Siswa: Kombinasi ORDER BY nilai DESC LIMIT 1 adalah sintaks resmi untuk mencari Juara 1 di sekolah!
✏️ Bab 8: UPDATE & DELETE
Modifikasi Data
UPDATE memperbarui data baris yang sudah ada, sedangkan DELETE menghapus baris data. Wajib menggunakan klausa WHERE!
-- 1. Memperbarui nilai siswa tertentu UPDATE siswa SET nilai = 95.0 WHERE nisn = '1001'; -- 2. Menghapus 1 data siswa berdasarkan ID DELETE FROM siswa WHERE id = 3;
⚠️ PERINGATAN GURU: Jangan pernah menjalankan UPDATE atau DELETE tanpa WHERE, karena akan menghapus atau mengubah SELURUH baris di tabel!
📈 Bab 9: Fungsi Agregasi & GROUP BY
Statistik Data
Fungsi agregat merangkum angka statistik: COUNT() (hitung jumlah data), AVG() (rata-rata), SUM() (total), MAX() (tertinggi), MIN() (terendah).
-- Rangkuman nilai rata-rata & jumlah siswa per kelas SELECT kelas, COUNT(*) AS total_siswa, ROUND(AVG(nilai), 1) AS rata_rata, MAX(nilai) AS nilai_tertinggi FROM siswa GROUP BY kelas;
💡 Tips Siswa: Gunakan HAVING (bukan WHERE) jika ingin memfilter kondisi setelah pengelompokan GROUP BY selesai dihitung.
🔗 Bab 10: Relasi Tabel (INNER JOIN)
Relasi Antar Tabel
INNER JOIN menggabungkan data dari dua tabel berbeda yang dihubungkan oleh Foreign Key. Mengeliminasi data duplikat dan menjaga normalisasi basis data.
-- Menggabungkan tabel siswa & tabel kelas SELECT siswa.nama, siswa.nilai, kelas.nama_kelas, kelas.wali_kelas FROM siswa INNER JOIN kelas ON siswa.kelas_id = kelas.id;
💡 Tips Siswa: INNER JOIN hanya menampilkan baris data jika kedua tabel saling cocok (memiliki ID kelas yang sama).
🐍 Bab 11: Menghubungkan Kode Python ke Database (sqlite3)
Praktik Koding Industri
Di dunia kerja, kode Python menghubungkan aplikasi backend langsung ke database untuk menyimpan dan mengambil data. Modul bawaan Python sqlite3 memungkinkan kita mengeksekusi query SQL dengan mudah dan aman.
import sqlite3 # 1. Buka koneksi ke file database sekolah conn = sqlite3.connect("studio_ml.db") cursor = conn.cursor() # 2. Eksekusi query dengan parameter binding (?) yang aman dari SQL Injection cursor.execute("SELECT nama, kelas, nilai FROM students WHERE class_name = ? ORDER BY nilai DESC", ("XI RPL",)) # 3. Ambil seluruh baris hasil query siswa_lulus = cursor.fetchall() for no, row in enumerate(siswa_lulus, start=1): print(f"#{no} {row[0]} ({row[1]}) -> Skor: {row[2]}") # 4. Tutup koneksi memori conn.close()
💡 Tips Standar Industri: Jangan pernah memasukkan variabel Python langsung ke string SQL dengan f"SELECT ... WHERE id = {id}" karena dapat dieksploitasi dengan SQL Injection! Selalu gunakan tanda tanya (?) sebagai parameter binding.
